# Source and attribution

This extension is a local implementation for `alex-pi-settings`.

Agent discovery and the compatible `subagent` tool contract were derived from the MIT-licensed Pi example:

- Package: `@earendil-works/pi-coding-agent` 0.87.0
- Repository: https://github.com/earendil-works/pi
- Example: `packages/coding-agent/examples/extensions/subagent/`

The RPC worker manager, Agent Hub UI, background worker controls, tests, and configuration in this directory are local additions. `LICENSE` preserves the upstream MIT license for derived portions.
